# Daily Cloud Practice Checklist :

Goal: Build daily momentum in learning + labs + interview readiness.

---

### Step 1: Learn a Concept (30 mins)
- [ ] Watch or read a short tutorial (AWS/Azure/GCP)
- [ ] Summarize 3 key takeaways
- [ ] Write 1 real-world example

### Step 2: Hands-On Practice (30 mins)
- [ ] Complete one hands-on lab
- [ ] Test a CLI/CloudShell command
- [ ] Save screenshots to GitHub/Notion

### Step 3: Interview Simulation (30 mins)
- [ ] Practice 2-3 technical questions
- [ ] Write 1 STAR-format behavioral answer
- [ ] Use ChatGPT: "Act as a cloud admin interviewer and ask 3 scenario questions."

### Step 4: Reflect & Log (30 mins)
- [ ] Write a short summary of today's learning
- [ ] Update GitHub 'Learning Log'
- [ ] Post weekly progress on LinkedIn (optional)
